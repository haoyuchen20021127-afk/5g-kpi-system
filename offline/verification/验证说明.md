神经网络原结果包含 GPU 运算，本次 CPU 复核允许绝对/相对误差各 2×10⁻⁵；传统预测允许各 10⁻⁹。检测分数允许各 10⁻¹⁰，异常标记要求完全一致。详细检查行数、误差及容差见 JSON。

全量 LSTM 检查发现：DONeXT latency 的 54,512 个标量预测中，1 个 CPU 预测超出上述严格容差，最大绝对差约 0.000029713（Z-score 尺度）。未通过放宽阈值隐藏这一例外。随后使用相同保存权重与原 CUDA 运算方式重放四个任务，所有结果均通过绝对/相对容差各 10⁻⁶ 的比较，最大差约 5×10⁻¹²。该证据支持差异来自 CPU/GPU 数值运算，而非模型或数据被替换；CPU 与 GPU 结果不能承诺逐位相同。

## 哪些文件是证据

- offline_audit.json：文件核对、100 组预测和 40 组检测抽样检查。
- workflow_smoke.json：15 个公共入口/网页/边界/临时重训流程的执行结果。
- full_lstm_comparison.json：4 个 LSTM 全测试集的逐行比较结果。
- gotsf_web_regression.txt：原 12 项网页自动化测试日志。
- task_inventory.json 与上级的任务与数据清单.md：实际任务、模型数和数据划分数量。

最终 ZIP 校验结果另外放在压缩包旁的交付校验 JSON 中，包含压缩包校验值、文件数及本地 Git 提交号。

3. 没有改变历史预处理、训练/验证/测试划分、模型权重和阈值；没有解决历史实验已说明的信息泄漏或缺少故障真值等限制。
4. 已在原 Windows / Python 3.13.12 环境验证。换电脑后的全新依赖安装尚未验证；需要按 README 安装对应版本。
