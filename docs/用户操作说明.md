# GOTSF 系统操作说明

## 打开系统

按工程根目录 README 启动。页面左侧可以在“KPI 预测”和“异常检测”之间切换。主内容位于可滚动区域，鼠标放在内容区内滚动。左侧控件改变后，页面会重新显示；是否重新计算由按钮控制。

## 预测页面

| 控件 | 用途与使用方式 |
|---|---|
| 功能模式 | 自定义输入用于试验；历史测试查询用于评分和筛选 |
| 查看 KPI | 只影响展示，不改变模型始终输入和输出 4 项的事实 |
| 测试样本 | 载入该样本前 24 小时，目标是下一小时 |
| 编辑表格 | 双击数值，输入后按 Enter；输入是 Z-score，允许负数 |
| 恢复原始输入 | 丢弃当前修改，重新载入所选窗口 |
| 批量调整 | 指定 KPI、最后 1 至 24 小时及增加量，点“应用”后写入草稿；多次点击会累加 |
| 预测并比较 | 用同一个冻结模型预测原输入与修改后输入，展示 4 项结果及变化量 |
| 训练范围提示 | 只是提醒输入超出模型见过的范围，不自动截断或证明异常 |
| 历史预测按钮 | 对全部 144 个测试窗口运行一步预测，真实值只用于对照与评分 |
| 时间与误差筛选 | 可筛选时段、预测值高于阈值、绝对误差高于阈值或误差 Top N |
| MAE RMSE R² | 衡量当前所选真实值与预测值的差异；须同时看样本数，不与不同筛选条件直接比较 |
| CSV 下载 | 保存当前输入或结果用于复核，不改变服务器保存的数据 |

示例：载入第一个窗口，将 DLPRB 最后 3 小时统一增加 0.30，再运行前后比较。0.30 是 Z-score 的增加量，不是增加 30% 的资源利用率。输入变化后原来的结果会失效，须重新点击预测。

## 异常检测页面

| 控件 | 用途与使用方式 |
|---|---|
| 检测功能 | 在历史查询与自定义单小时试验之间切换 |
| 检测方法 | 四种方法独立运行，不是投票；沿用已保存阈值 |
| 小区编号 | 选择 90 个已有小区之一 |
| 测试时段 | 选择 840 至 1007 或 1680 至 1847 小时，两段不拼接成连续时间 |
| 查看 KPI 曲线 | 切换观测和分数图，不影响每次检测全部 4 项 |
| 运行异常检测 | 当前方法检测所选小区及时间段；换小区、时段、方法后需重跑 |
| 小时范围滑块 | 只筛选已有结果，不重新训练或校准 |
| 记录级计数 | 至少一项异常则整条异常；全部有效且未异常才是未判异常；其余为无法判定 |
| 红色观测点 | 表示该 KPI 被当前方法标记，灰色参考曲线不是 LSTM 预测 |
| 分数和阈值图 | 严格高于有效阈值才判疑似异常；不同 KPI 或方法的分数不能直接比大小 |
| 表格只看疑似异常 | 只筛表格及对应下载，不改变上方计数和曲线范围 |
| 三类下载 | 分别导出记录级结果、当前 KPI 明细、全部 4 项 KPI 明细 |

自定义模式选择一个已有小时，修改“当前输入值”，不能改 KPI 名和原始值。使用数据集源尺度的非负数，不要填预测页的 Z-score。点击“检测并比较修改前后”，可展开查看去日周期和缩放过程。附近原始曲线只用于背景对照，不参与单点判定。

示例：选择小区 0_0、时段 test_5w-6w、小时 840、孤立森林，将 DLPRB 改为 2。该项从未判异常变为疑似异常，另外 3 项分数不变。这个试验说明模型对输入的反应，不意味着真实发生故障。

## 常见问题

- 浏览器“拒绝连接”：确认启动终端仍在运行，再检查端口。关闭浏览器不会替你启动服务。
- 分数为负：分数来自模型的评分方向，允许负数；只和当前模型阈值比较。
- 项目相对小时：从数据项目起点累计的小时，不是当天几点，也不是日历日期。
- 改完数据没更新结果：先按 Enter 确认表格输入，再点击预测或检测按钮。
- 假设输入异常：这是模型判定，不是因果证明或工程故障确认，需要业务和设备日志复核。
