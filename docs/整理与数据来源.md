# 工程整理与数据来源

本版面向第八周交付，只保留 GOTSF Web 所需功能。原 E 盘 Week1 至 Week7 目录均保留，作为备份；未删除、回退或提交这些目录中用户已有的修改。

## 清理范围

- 预测页由原先混合脚本拆为 UI 与服务，模型仅保留 JointLSTM；移除运行时对多数据集模型工厂、GRU、Transformer 和传统模型代码的依赖。
- 去掉动态载入旧目录 Python 文件的逻辑。所有数据路径相对于当前工程解析。
- 检测器去掉 GOTSF 不使用的 CQI、PCMAX、RI 特例及类别保留采样分支。
- 不携带旧 `.bak`、临时文件、缓存、虚拟环境、5 条数据旧演示 CSV 和重复导出。
- 保留关键注释、输入一致性校验、阈值数值保护、缓存失效参数、页面草稿状态和结果失效逻辑。这些即使看起来不直接用于计算，也不能随意删除。

## 资产来源

预测数据和 LSTM seed 42 来自原 `week5/all_models_comparison/outputs/gotsf_ds/joint_kpi`。异常观测、模型输入、模型及阈值来自原 `week6/交付物_所选KPI/results/datasets/gotsf_ds`。UI 来自用户最后修改的 Week7 版本。原始训练清单中的旧路径只作为来源记录，不在运行时读取。

异常模型迁移仅更换 Python 包装类的模块路径，保留已经拟合的 sklearn 对象与参数；因此 joblib 文件哈希变化，但所有测试分数与标记逐项核对。LSTM 权重文件原样复制。资产哈希在 `evidence/asset_manifest.json`，迁移核对在 `evidence/migration_audit.json`。

`evidence/*_archived_metrics.csv` 是先前 GOTSF 多模型实验的指标档案，不表示这些模型已集成到当前网页。本版推理只提供 LSTM。

根因案例来自第六周根因报告，小区 1_1 的 1724 至 1750 小时事件。报告中的相关性及经多重比较校正的区间是已完成实验的引用，不因本版仅保留 GOTSF 而改为更宽松的检验口径。此功能没有伪装成网页自动根因诊断。

## 可复现边界

本项目从已处理数据开始，可以复核推理并按已选参数离线重训。未包含 4 套原始数据的完整清洗过程，也未将所有早期实验复制进交付目录；这些保留在旧工程。预测沿用全源统计预处理的局限仍然存在，本次代码整理不会消除它。

已完成本机 CPU 推理与页面自动化验证，不宣称已经完成新电脑的全新安装、生产部署、并发压测或真实故障定位。未来公开上传前还需核实数据再分发许可。
